What is an "estate" vs a "property"?

This defines the core data model. Does one estate contain many individual units, or is each home a standalone property?

A

Estate → many units (apartments/houses)

A single estate project (e.g. "Saulėtekio kvartalas") contains many individual units. Each unit has one owner. The company builds the estate; owners buy individual units.

Data model: Estate → Units → Owner

B

Each property is standalone

No parent "estate" concept. Every property (home, apartment) is its own entry in the system, and the company manages each one independently. One owner per property.


Data model: Property → Owner

C

Estate → units, but one owner can own multiple units

Same as A, but an owner (e.g. an investor) can be linked to several units across one or more estates. More flexible ownership model.


Data model: Estate → Units ←→ Owners (many-to-many)
