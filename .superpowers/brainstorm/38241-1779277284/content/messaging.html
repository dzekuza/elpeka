How do owner requests / messages work?

This determines whether we need real-time messaging infrastructure or a simpler ticket system.

A

Simple ticket / request form

Owner fills a form (subject, category, description). Company staff sees it in the CMS, marks it as resolved. Email notifications on both sides. No live chat — async only.

B

Threaded messages per unit

Each unit has a message thread. Owner and staff exchange messages like an email thread — no live chat, but full conversation history. Email notification on new message.

C

Real-time chat (Supabase Realtime)

Live messaging between owner and company. More complex to build, but feels modern. Still email notifications as fallback when offline.
